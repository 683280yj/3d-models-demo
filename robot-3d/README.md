# 六轴工业机器人 · 高精度 3D 交互仿真（本地复刻/自建）

架构与 `diesel-engine-3d` 完全一致：**单文件 HTML + 程序化几何 + 本地 Three.js**。
用同样的"正向运动学 + 交互"套路，把柴油机换成了 6 轴工业机器人臂。

## 技术栈
- 原生 HTML/CSS/JS（无框架、无打包）
- Three.js `0.160.0`（ES Module，本地 `vendor/`）
- 机器人**全程序化生成**：6 个嵌套 Group 构成运动学链（J1 基座回转 → J2 大臂 → J3 小臂 → J4 翻转 → J5 腕俯 → J6 腕转 → 夹爪），无外部模型/纹理/接口

## 文件结构
```
robot-3d/
├── index.html          # DOM + 内联 CSS + 内联 module 脚本
├── vendor/             # 本地 Three.js（同 diesel 项目）
└── README.md
```

## 功能
- 6 轴关节：拖动左下 6 个滑块手动示教；运行中滑块跟随实时角度
- **自动运行**：抓取-放置循环（接近→抓取→抬起→转身→放置），夹爪开合 + 工件随动，循环计数
- 实时 **TCP 位置/速度** 解算（读取末端世界坐标）
- 零件悬浮信息卡（名称/材料/功能/参数/实时关节角或夹持状态）
- 视角预设：自由 / 侧视 / 俯视 / 正视
- fps、阴影、环境光照

## 启动
ES Module + importmap 需经 HTTP（`file://` 会被浏览器拦截）：
```bash
cd robot-3d
python3 -m http.server 8124
# 打开 http://127.0.0.1:8124
```

## 想改成别的"机器人"？
- 人形/四足：把运动学链换成腿/躯干结构，复用同一套 hover/滑块/视角逻辑即可。
- 换末端工具：改 `grip` 组（焊枪/吸盘/喷涂头），信息卡参数一并更新。
- 加载真实模型：若以后要用 `.glb`，引入 `three/addons/loaders/GLTFLoader.js` 替换程序化几何，其余交互不变。

## 限制
无外部依赖，断网可跑。运动学为正向（给定关节角求位姿），未做逆解（给定目标点求关节角）。
