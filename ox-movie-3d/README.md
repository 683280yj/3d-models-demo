# 牛来 · THE BULL ARRIVES — Three.js 短片（剧情版）

一个 **程序化生成的单文件 3D 短片**，和前面的柴油机/机器人同一套路（单 HTML + 本地 Three.js + 程序化几何），只是这次是"叙事/运镜"而非"仿真交互"。

## 技术栈
- 原生 HTML/CSS/JS，无框架、无打包
- Three.js `0.160.0`（ES Module，本地 `vendor/`）
- 牛 / 妈 / 爸 / 蛇 / 小云雀 / 大树 **全程序化生成**，无外部模型/纹理
- 背景音乐 + 撞树音效用 **Web Audio API 实时合成**，无外部音频文件，断网可跑

## 剧情（约 40s）
1. **片头**：「牛 来 / THE BULL ARRIVES」
2. **妈跳河**：妈牛纵身跳过河，落到对岸
3. **讲大道理**：妈说"你跳过来就是成长了""你现在就得成长，不能总指望着以后长大"
4. **牛来拒绝**："我现在不想跳……我现在，不想长大"（低头 + 眼泪）
5. **云雀报信**：小云雀飞来说"快看——你后面有蛇！"
6. **吓一跳**：牛来吓得蹦过蛇，却一头撞上大树（"哐!!" + 音效 + 镜头抖）
7. **爸神补刀**：爸出现问"你怎么撞到树上了？"，牛来哭，爸说"你撞到树了，树不应该哭吗？"
8. **片尾**：「— 完 —」演职表

## 交互
- 播放中：时间线全权接管镜头
- 暂停后：可左键拖拽自由观察（OrbitControls 启用）
- **音乐**：点任意处或「播放」开启（浏览器自动播放限制）；右下「🔊 音乐」可静音
- 「重播」：从头播放

## 启动（必须 HTTP，file:// 会被拦截 ES Module）
```bash
cd ox-movie-3d
python3 -m http.server 8125
# 打开 http://127.0.0.1:8125
```

## 想改？
- 改台词：编辑 `SCRIPT` 数组（`who`/`t0`/`t1`/`text`，`punch:true` 为强调大字）
- 改镜头：编辑 `CAM`（`t`/`p` 机位/`l` 看向）
- 改走位/跳跃：牛来 `leap(-8,9,23,25.5,...)`、妈 `leap(-8,8,6,9,...)` 的参数
- 改配乐：调 `PENTA` 音阶、`scheduleArp` 步长；音色在 `playNote`/`startAudio` 里
